使用技術と取り組み

プロジェクトで使用した技術と主な作業内容を紹介します。

分野 使用技術 主な作業 目的
データ加工 SQL Server データの整理・変換 分析に使える形へ整える
データ分析 SQL・Python 集計・分析 傾向や課題を把握する
データ可視化 Power BI ダッシュボード作成 結果を直感的に伝える

データウェアハウス構築

ERPやCRMのCSVデータを取り込み、Bronze・Silver・Goldの層に分けて整理するデータウェアハウスの構築例です。

データクリーニング

欠損値や重複、データ型の不整合を確認し、分析の前提となるデータ品質を整えます。

売上・商品分析

売上や商品別の実績を集計し、数値の変化や特徴を把握するための分析例です。

ダッシュボードによる可視化

分析結果をグラフや主要指標にまとめ、データをもとに状況を比較・判断しやすくします。
